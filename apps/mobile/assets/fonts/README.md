# Fonts (mobile)

Native brand wordmark uses **Nunito ExtraBold** via `@expo-google-fonts/nunito` (`Nunito_800ExtraBold`), loaded with `expo-font` / `useFonts`.

Do not place `.woff` / `.woff2` files here for native loading.
